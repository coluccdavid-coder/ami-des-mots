# Ami des Mots — évolution graphique v5.49

## Ce qui change
- Trois profils graphiques dans le monde 3D : Auto, Ultra et Éco.
- Profil Ultra : exploite jusqu'à 2,5× le pixel ratio sur ordinateur (selon l'écran et le GPU), avec ombres haute définition jusqu'à 4096 px.
- Profil Auto : compromis adaptatif, avec baisse automatique en cas de performances faibles.
- Profil Éco : désactive les ombres dynamiques et les effets de particules décoratifs pour les appareils modestes.
- Le choix est conservé localement dans le navigateur.

## À savoir sur la 4K
Le jeu peut rendre jusqu'à une définition physique correspondant à un écran 4K lorsque l'écran, le navigateur et le GPU le permettent. Le profil Ultra ne transforme pas un écran Full HD en écran 4K et ne convertit pas les modèles low-poly existants en personnages photoréalistes. Les personnages riggés et animés existants sont conservés.
